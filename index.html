Recurso técnico

¿Qué vial
necesitás para
tu aplicación?

Guía de selección de viales desarrollada por nuestro equipo técnico. Técnica, material de vidrio, tipo de cierre, septa y compatibilidad con el automuestreador.

Consultá a nuestro equipo
01
¿Para qué técnica?
HPLC, GC, GC-MS o headspace. Cada técnica define el perfil del vial.
02
¿Qué automuestreador usás?
Agilent, Waters, Shimadzu u otro. El fabricante condiciona la geometría del vial.
03
Tipo de vidrio y septa
Borosilicato clase 1 para trazas. Vidrio ámbar para fotosensibles. PTFE/silicona como estándar.
04
Tipo de cierre
Rosca para HPLC general. Crimpeado para GC headspace. Snap-cap para alta velocidad.
05
Original o compatible
Los viales AGS son dimensionalmente equivalentes a Agilent. Para métodos validados, recomendamos verificar el cambio.
